# 0001: Hierarchical Orchestration Analysis with Contract-Key Resolution

To handle "Large-Giant" monorepos (10,000+ files) without hitting LLM context limits or causing hallucinations, we have decided to implement a 4-phase hierarchical discovery protocol. Instead of a monolithic AST or exhaustive file reading, the system uses a 2-pass heuristic signature-based module map (Level 1) to identify suspicious cross-module paths, followed by a deterministic polyglot "Contract-Key Resolution" engine (Level 2) that stitches disparate language ASTs via universal contract identifiers (e.g., `grpc://`, `event://`). This approach prioritizes non-code artifacts (IDLs like `.proto`, IaC) as high-signal anchors to ensure analysis reflects declared system intent. Finally, a "Challenge-Response" synthesis loop (Phase 4) validates subagent findings against global middleware snippets found via RLM search to eliminate false positives caused by isolated context gaps.
